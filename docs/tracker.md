## Maintenance Workflow

1.  Commit before significant changes.
2.  Make the changes.
3.  Run tests and production build.
4.  Fix failures and re-run checks.
5.  Push to `main` after verification.
6.  Confirm the Vercel deployment actually completed.
7.  Record the result and any follow-up tasks.
